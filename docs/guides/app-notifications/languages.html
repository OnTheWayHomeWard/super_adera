Languages

Which language a notification is written in, and what happens when the template lacks that language.

Overview

Templates (written by Adera staff) hold text per language: en, am, om. The language used for a user is their profile language (language on the user's profile, one of en, am, om, default en; changed through the profile endpoint described in the Account guide).

Rules

  1. The text is rendered at delivery time using the language the user has then.
  2. If the template has text for that language, it is used.
  3. If it has not, the English text is used. The fallback is per text, so a template with an Amharic body but no Amharic title shows the Amharic body with the English title.
  4. English is mandatory: an IN_APP template cannot be saved without an English title, so title and body are never empty.
  5. The placeholder values (params) come from the partner and are inserted as sent; they are not translated. A partner serving Amharic users should send localised values if it wants a fully Amharic sentence (the example shows 7 min inside an Amharic sentence).
ThingLanguage used
Inbox title / bodyUser's profile language, fixed when delivered; later language changes do not re-translate existing items.
Push title / bodySame text as the inbox item.
SMSThe template's sms text in the user's language (if that language has no sms text, the English sms text; if there is none at all, the body).
EmailSubject and HTML from the template in the user's language.
Device localeNot used for notifications.

Captured example

The same template seed-order-update exists in en, am and om. The seeded user above has language am, so the inbox item was Amharic: ትዕዛዝዎ በመንገድ ላይ ነው (en: "Your order is on the way"). A user with om would get the Afaan Oromo text; a template without om would give that user the English text.

Client notes

  • Render with a font that covers Ethiopic script and test long Amharic strings in the notification row (title up to 100, body up to 1000 characters).
  • The app's own UI language and the notification language are independent settings: the notification language follows the server-side profile language, so make sure the app saves the user's chosen language to their profile.
