Super app: notifications, inbox and push

How a message sent by a mini app reaches the person using the Adera app, what the app can read (the notification inbox, the bell badge, the push payload), and what the user can switch off.

Audience

Super-app client developers (the mobile or web app) and backend colleagues who need to know what the user will see for a given partner request. Partner request signing is covered in the Partner API guide, device-token registration in the Account guide; this guide refers to them as text only.

What this guide covers

  • How a partner request becomes an SMS, an email, or an in-app inbox item plus a push.
  • The inbox API behind the bell icon: list (paging, unread filter), unread count, mark read, mark all read.
  • The push payload the client receives, and what "fake" versus real Firebase means today.
  • Per-app mute switches and exactly what they stop.
  • Which language a notification is written in.
  • What the user never sees, and what happens for unreachable or suspended users.
  • Practical recipes: unread badge, deep links, paging, empty states.

Conventions

TopicRule
Base URLAll paths are relative to the gateway: $GATEWAY (dev: http://127.0.0.1:9080). Clients never call a service port.
Authuser session: Authorization: Bearer $TOKEN (the Kratos session_token). The gateway checks it and injects the user id; a client can never read or change another user's inbox. The inbox and the preference/device calls are all user-session calls; there is no staff or partner call in this guide except the partner request shown as context.
Error shape{"error": "code"}; validation errors add "fields": {"name": "message"}. Errors produced by the gateway (401, 429) are not JSON in that shape; see Error codes.
IdsUUIDs (lower case, hyphenated). The inbox item id is not the partner's notificationId and not the partner's externalId.
TimestampsISO 8601 in UTC, e.g. 2026-10-26T10:51:15.474Z. readAt is null until read.
Paginationpage (0-based) and size (1 to 100, default 20). There is no total count and no cursor.
Languagesen, am (Amharic), om (Afaan Oromo). The text is written when the notification is delivered, in the user's profile language.
Placeholders$GATEWAY, $TOKEN (session token), $ITEM_ID (inbox item id). Examples were captured on 2026-10-26 on the dev stack with a seeded demo user and the seeded demo-food mini app; throwaway rows were removed afterwards.

Glossary

TermMeaning
Super appThe Adera app the user installs.
Mini appA partner service listed in the super app (for example demo-food).
PartnerThe server of a mini app. It asks Adera to notify a user; it never talks to the user's phone directly.
AliasThe pseudonymous id a partner uses for a user (u_p_...). The user's real id and the alias are never shown to each other's side.
TemplatePre-approved message text with placeholders, created by staff for a mini app, with kind IN_APP or DIRECT.
InboxThe list behind the bell icon; one item per IN_APP notification that was delivered.
PushA Firebase Cloud Messaging (FCM) message that makes the phone show a banner. Best effort, on top of the inbox.
MuteA per-user, per-mini-app switch for in-app, SMS or email messages.
Notification idThe partner-facing id of the request (notificationId). It appears in the push payload but not in inbox items.
