Known issues and not built yet

Limits of the first version, and decisions taken where the design was silent.

Not built yet

  • No targeting by market, language, user group or app version: every user sees the same banners.
  • No impression or tap counting on the server.
  • No list of the adera:// screens the server could check targets against.

Decisions

  • The list is public (no sign-in), so banners can be shown before login.
  • Visibility is computed on every request; nothing is stored when a banner starts or ends.
  • The external-domain allow-list is checked when a banner is saved, not on every read.
