Banners in the super app

How the Adera app fetches the promotional banners for a screen, renders them, and what it does when the user taps one: for super-app (client) developers.

Audience

Super-app developers: the Adera mobile and web client team. Banners are created and scheduled by Adera staff in the backoffice; the app only reads them. Nothing here links outside this folder: it can be zipped and shared on its own.

Overview

A banner is a picture with a title (and maybe a subtitle) shown in one of four places in the app. Tapping it opens a mini app at a given page, a screen of the super app, a web page on an approved domain, or nothing. The app asks one public endpoint for the banners of a placement; the server answers with only the banners that should be showing right now, highest priority first, with three image sizes and everything needed to act on a tap.

Why it is built this way

Staff schedule banners ahead of time and pause them in an emergency, and a banner for a mini app must vanish when that app is suspended. If the app decided any of that, old app versions would show stale or unsafe banners. So the server decides what is visible at every request and the app renders exactly what it gets.

Conventions

  • Base URL. Everything goes through the gateway: $GATEWAY is http://127.0.0.1:9080 on the dev stack (the staging server and the public API host later). Paths are exactly what the client calls.
  • Authentication. None: the banner list is public, so it works on the home screen before sign-in. Sending the user's Authorization header does no harm and changes nothing.
  • Errors have the shape {"error": "<code>", "fields": {...}}. See "Error codes".
  • Languages. title and subtitle are objects with up to three languages (en, am, om); English is always there. Show the user's language, else English.
  • Times are ISO-8601 UTC. Ids are UUIDs.

Glossary

TermMeaning
PlacementWhere a banner is shown: HOME_HERO, FEATURED, PROMOTIONS, CATALOG_TOP.
CategoryWhat it is about: PROMOTION, FEATURED_APP, ANNOUNCEMENT, EVENT. Useful for a small label or a filter.
Action typeWhat a tap does: MINI_APP, INTERNAL, EXTERNAL, NONE.
TargetWhere the tap goes: a route inside the mini app, an adera:// link, or an https URL.
Linked appThe mini app a banner is about. Its banners disappear by themselves while the app is not live.
Image sizessmall (longest side 480 px), medium (960), large (1600), JPEG.
