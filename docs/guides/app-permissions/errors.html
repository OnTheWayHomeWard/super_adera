Error codes

Every error code of the permission API and the backend profile and notification calls, with what to do.

Overview

Every error of our services has the shape {"error": "<code>", ...details}; validation failures add fields. Errors produced by the gateway (an empty 401, a 429 page) are not in that shape. Statuses and codes below were produced by the running dev stack.

All codes

StatuserrorWhenWhat to do
400validation_failedA field is not acceptable: fields.capability not a capability key, fields.state not GRANTED or DENIED, fields.answer, missing fields.promptId, unknown field.Fix the call. The body names the field.
401(empty body, gateway)No session, an expired or revoked one.Sign the user in again.
403app_not_liveThe mini app is paused or killed.Show that the app is unavailable. Disconnect still works.
403capability_not_grantedStaff did not grant that capability to the app (answer, menu, or a profile field).Stop; for a mini app: ask Adera.
403consent_requiredThe user did not allow it. Body: capability, state (NOT_ASKED, DENIED, BLOCKED). Seen by mini-app backends (profile, notifications).Do not loop. Send the user to the page to ask, or go on without.
403account_suspended / account_deletedThe user's account is not active.Sign the user out.
403wrong_environmentA partner key of the other environment (DEV key on prod or the reverse).Use the key of the deployment you call.
404not_foundNo such app, or the app is a draft.Drop the app.
409prompt_invalidAn answer with no open prompt, another prompt, an already used one, or for another user, app or capability.Call request again.
409prompt_expiredThe prompt is older than 5 minutes.Call request again.
409use_disconnectA menu switch tried to deny user.basic alone.Offer Disconnect.
422user_unreachablePartner calls: unknown alias, an alias of another app, deleted or suspended user.Do not retry.
422synthetic_user_not_allowedA u_p_test_* alias on a PROD deployment.Test users exist in DEV only.
429(gateway)Over the gateway limit (30 per minute for the dialog request, 60 for launch, 300 for the rest).Wait and retry.
503service_unavailableThe registry or the signer could not be reached.Retry later.

The bridge's own codes

The bridge turns these into its own error.code values (app_not_live, prompt_expired, session_expired, account_not_active, service_unavailable, ...). See the table at the end of the bridge specification page.
