Errors

Every error code the admin API and the partner API return in this area, and what to do about each.

The error shape

Every admin API error is a JSON object with an error code and, where useful, more fields. Match on the error code, not on the message text.

HTTP 400
{
  "error": "validation_failed",
  "fields": {
    "extraField": "unknown field",
    "code": "required: 2-60 chars of lowercase letters, digits, '_', '.', '-' (e.g. job-accepted)",
    "kind": "required: DIRECT (SMS or email) or IN_APP (inbox + push)",
    "category": "must be TRANSACTIONAL, REMINDER or PROMOTIONAL",
    "params": "each name must be unique, start with a letter and use letters, digits or '_' (max 30)",
    "content": "unsupported language 'fr' (use en, am, om)"
  }
}

HTTP 409
{
  "error": "not_ready_for_live",
  "fields": {
    "missing": "logo,supportEmail"
  }
}

HTTP 403
{
  "error": "insufficient_role"
}
  • fields holds one message per bad field (validation errors), or details of a conflict (not_ready_for_live: fields.missing; too_many_active_keys: fields.max). Field keys use dots for nested places: content.en.body.
  • Errors from the notification service's admin endpoints (templates, log, usage) have the same shape.
  • Two answers do not use it: a gateway rate-limit 429 (the gateway writes its own body) and a path that does not exist (the framework's default JSON, below).
GET /admin/api/v1/apps/$APP_ID/nope
HTTP 404  {"timestamp": "2026-10-26T11:16:24.497Z", "status": 404, "error": "Not Found", "path": "/admin/api/v1/apps/ff6510a9-de00-4fb2-97a4-ce4ad6e377dd/nope"}

Access and gateway errors

StatuserrorMeaningWhat to do
401unauthorizedNo token, an unknown or expired session, or the staff member is disabled.Sign in again (staff sign-in).
403mfa_requiredThe session is aal1 (authenticator step missing).Complete the authenticator step.
403not_staffSigned in but not an active staff member.A SUPER_ADMIN adds the person.
403insufficient_roleYour role is too low.Ask a higher role; see the matrix.
403only_super_admin_can_revive_killed_appADMIN tried to leave KILLED.A SUPER_ADMIN makes the call.
429(gateway)Over 300 requests per minute from one IP.Slow down.
503identity_service_unavailable / gatewayThe identity service or registry is unreachable while checking the token.Retry; check service health.

409template_code_takenCreate templateThe app already has this code.Another code, or edit the template.

Partner-facing errors you will meet in tickets

These are returned to the partner's servers by the partner API (/v1/*), not to staff. Partners will quote them to you. Checks run in this order, top to bottom, so the first one that applies is the one the partner sees.

StatuserrorMeaningAdmin action that fixes it
413request_too_largeBody over 64 KB.Tell the partner (no admin action).
401missing_signatureKey id, timestamp or signature header missing.Partner bug.
401invalid_timestamp, stale_timestampTimestamp not a number, or more than 5 minutes off Adera's clock.Partner must fix its clock.
401unknown_keyNo such key id.Check that the key id is right and registered for this app (Partner keys).
401key_revoked_or_expiredThe key was revoked or is past expiresAt.Register a new key (rotation runbook).
401invalid_signatureThe signature does not match (wrong private key, changed body, wrong path).Compare the fingerprint; the partner re-checks signing.
403wrong_environmentA key of the other environment (a PROD key used on the dev deployment, or the reverse).Register a key for the right environment.
401unknown_appThe key's app no longer exists.Data problem; check the app.
403app_draft, app_paused, app_killedThe app status does not allow calls here (PROD needs LIVE; DEV refuses only KILLED).Change the status if appropriate (Status lifecycle).
403ip_not_allowedThe caller's address is not in the allowed list for this environment.Add the address (runbook 6).
503service_unavailableAdera could not reach its own registry or user service, or the two services disagree on ADERA_ENV.Operations: check services and the environment setting.
400validation_failedThe send request is malformed (fields).Partner bug.
409external_id_reusedThe same externalId was used for a different request.Partner must use unique ids.
404template_not_foundTemplate id of another app or unknown.Give the partner the right template id.
422template_inactive, template_not_yet_valid, template_expiredThe template is switched off or outside its window.Activate or extend it (Templates).
422param_invalidA value is missing, too long, has a link, or is not declared (fields).Partner bug, or change the template's params.
422user_unreachableThe user is unknown to this app, deleted, suspended, or has no contact for the channel.None; tell the partner.
422synthetic_user_not_allowedA u_p_test_* user in PROD.Partner uses real user ids in PROD.
403capability_not_grantedThe channel needs a capability that is not GRANTED (capability says which).Grant it (Capabilities).
429quota_exceededA notification limit was hit (limit, channel).Raise the limit (runbook 5), or wait.
