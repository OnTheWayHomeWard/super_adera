Adera backend documentation

Everything about the Adera backend in one place: what it is, how to run it, every tool and service, how requests travel, how it is secured, what is in the databases, every endpoint with real examples, step-by-step guides and reference tables. It works offline: open this file from disk.

Last verified

2026-10-25, against the running development stack (all 17 containers up) and the source in services/ and infra/. Examples were captured from the live stack through the gateway in dev mode (console SMS, Mailpit); nothing real was sent. Where these pages and older notes disagree, the code and the running system won, and the page says so.

Versions: Spring Boot 4.1 on Java 21, Kratos v26.2.0, APISIX 3.19.0, Postgres 16, Redis 7, RabbitMQ 4, Infisical v0.167.2, RustFS 1.0.3, Grafana 13.0.2.

Conventions used in these pages

  • Examples are real. Requests and responses were captured from the running stack. Where something was masked it says so: phone numbers look like +2519*****20, emails like a***@example.com, and secrets, tokens, password hashes, keys and HMACs are never shown (placeholders such as $TOKEN and <masked> stand in). Identifiers in examples belong to throw-away test data that was deleted afterwards.
  • "Illustrative example" marks a row or response that could not be captured (for example a table with no rows yet); it is clearly labelled and is not real data.
  • Paths are as the client calls them (through the gateway at http://127.0.0.1:9080). The internal path is given where it differs.
  • Badges: built partial not built our code.
  • Light and dark follow your system setting; the Theme button overrides it. On a phone use the Menu button for the section list.
  • The earlier Markdown notes docs/SETUP.md and docs/PARTNER_API.md are kept as source material. These pages are the complete and authoritative version.
